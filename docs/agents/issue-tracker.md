# Issue tracker: GitHub

Issues and specifications for this repository are tracked with GitHub Issues. Use `gh issue` commands from this checkout. The configured remote is the upstream Postiz repository; do not create or modify issues there without repository authorization.

## Conventions

- Create issues with `gh issue create --title "..." --body "..."` only when authorized for the target repository.
- Read issues with `gh issue view <number> --json number,title,body,labels,comments`.
- Apply or remove labels with `gh issue edit <number> --add-label "..."` or `--remove-label "..."`.

## Pull requests as a request surface

No. External pull requests are not feature requests for triage.
